# ApexFlow 待办台账与敏捷项目管理工作区

现代极简个人**待办台账（Daily Task Ledger）**与高密度研发项目管理工具。原生集成 **端到端 AES-256-GCM 零知识加密**、云端容灾持久化同步、智能粘贴通知提取，以及看板、高密度列表、甘特图、日历排期与冲刺迭代全套工作流。

---

## 快速上手指南（导入 GitHub 后的本地运行步骤）

### 1. 环境准备
确保您的电脑上已安装以下环境：
- **Node.js**：`v18.0.0` 或更高版本（推荐 `v20.x` LTS）
- **包管理器**：`npm`（Node 自带）、`pnpm` 或 `bun`

通过终端检查版本：
```bash
node -v
npm -v
```

---

### 2. 克隆项目并安装依赖

克隆您在 GitHub 上的仓库到本地：
```bash
git clone https://github.com/您的用户名/您的仓库名.git
cd 您的仓库名
```

安装项目依赖：
```bash
npm install
```
*(若使用 pnpm 可执行 `pnpm install`，若使用 bun 可执行 `bun install`)*

---

### 3. 本地启动开发服务器

执行以下命令启动全栈服务（Express 具备云端加密存储 API + Vite 前端即时热更新）：
```bash
npm run dev
```

启动成功后，终端会输出访问地址：
```
ApexFlow full-stack server running on http://0.0.0.0:3000
```
在浏览器中打开 **`http://localhost:3000`** 即可开始使用。

---

### 4. 生产打包与部署

#### 本地构建预览：
```bash
# 1. 编译生产前端静态包
npm run build

# 2. 启动生产服务器
npm run start
```

## 🖥️ 打包为本地 Windows `.exe` 可执行桌面程序

本项目已内置完整的 Electron 桌面客户端配置，提供两种最便捷的 `.exe` 获取方式：

### 方案 A：通过 GitHub Actions 自动云端打包（推荐，无需本地配置环境）
1. 将项目代码推送到 GitHub 仓库。
2. 打开 GitHub 仓库页面，点击顶部的 **Actions** 标签。
3. 在左侧选择 **`构建 Windows 本地可执行文件 (EXE)`** 工作流。
4. 点击右侧 **`Run workflow`** 按钮开始自动打包。
5. 等待 2~3 分钟构建完成后，页面底部 **Artifacts** 中即可直接下载生成的 **`ApexFlow-Windows-EXE.zip`**，解压即可得到标准的安装包（`Setup.exe`）或单文件免安装绿色版（`Portable.exe`）。

### 方案 B：本地 Windows 电脑一键双击打包
若您在本地 Windows 电脑上开发：
1. 双击运行项目根目录下的 **`build-exe.bat`** 批处理脚本（或者在命令行运行 `npm run build:exe`）。
2. 脚本将自动完成依赖检查、前端打包及 Electron 安装与封装。
3. 打包完成后，进入生成的 **`dist-electron/`** 目录，即可直接运行生成的 `.exe` 桌面程序！

桌面版具备离线本地存储与服务端加密同步的完整支持，并拥有独立的系统原生窗口和快捷键。

#### 常见云平台一键部署推荐：

| 平台 | 部署方式 | 说明 |
| :--- | :--- | :--- |
| **Vercel / Netlify** | 直接连接 GitHub 仓库 | 构建命令：`npm run build`，输出目录：`dist` |
| **Render / Railway / Zeabur** | Web Service 服务 | 启动命令：`npm run start`，环境变量端口设置 `PORT=3000` |
| **Docker 容器** | 使用 Node 基础镜像运行 | 运行 `node server.ts` 即可提供 API 与前端托管 |

## 核心功能与安全架构

### 1. 待办台账（Daily Task Ledger）
- **实时统计看板**：待办中、已逾期、7天内到期、已完成 4 维指标快速穿透。
- **动态排期提醒**：结合当天日期自动提示今日到期事项。
- **智能粘贴解析**：在「新增事项」弹窗的智能粘贴框中粘贴通知、邮件、微信/飞书群消息，系统自动识别事项标题、部门、优先级及截止日期；亦支持直接粘贴剪贴板截图。
- **多维过滤**：时间跨度（全部/周/月/年）、状态胶囊过滤及快速关键词检索。

### 2. 端到端 AES-256-GCM 零知识安全体系
- **本地加密**：采用浏览器底层原生 `Web Crypto API`。数据在离开您的浏览器前，使用主密码通过 **PBKDF2（100,000 次哈希迭代）** 派生出的 256 位密钥完成 AES-GCM 强加密。
- **防篡改数字校验和**：生成随机 12 字节 IV、16 字节随机盐（Salt）与 **SHA-256 完整性哈希**。
- **云端保险箱（`/api/cloud-backup`）**：服务端仅存储密文字符串，服务器及任何第三方均无明文解密权限（零知识隐私保障）。
- **多版本快照回滚**：随时查看历史云端备份版本，一键解密还原。
- **双模导出**：支持一键导出标准 UTF-8 BOM CSV 明细报表，或导出 `.afenc` 离线加密密文卷。

### 3. 多视图自由联动
- **事项列表**：高密度单元格即点即改（状态/优先级/预估点/负责人）、按状态/优先级/项目多维分组。
- **日历视图**：月度排期网格，点击任意空白日期单元格直接预填排期新建事项。
- **看板视图**：标准待规划、待处理、进行中、评审中、已完成列，原生拖拽流转。
- **甘特图时间线**：多周跨度缩放与左右拖拽延长工期把手。
- **迭代冲刺**：冲刺交付达成率、未完成任务一键顺延。
- **团队负载**：个人故事点饱和度容量监控。
- **全局指令菜单 (`Cmd+K` / `Ctrl+K`)**：全键盘快速查找与跳转。

## 目录结构说明

```
.
├── server.ts               # Express 全栈服务入口（托管 Vite 与云端加密备份 API）
├── src/
│   ├── components/
│   │   ├── common/         # 状态图标、优先级图标、头像等原子组件
│   │   ├── modals/         # 云端加密保险箱 (CloudVaultModal)、新增事项、命令菜单
│   │   └── views/          # 待办台账 (DailyTaskLedgerView)、看板、列表、甘特、日历等
│   ├── context/            # 全局响应式状态与本地持久化 (ProjectContext)
│   ├── data/               # 初始模拟示例数据 (mockData)
│   ├── types/              # TypeScript 数据模型与接口定义
│   ├── utils/              # AES-256-GCM 加解密工具与 CSV 导出生成器 (crypto)
│   ├── App.tsx             # 视图路由与工作区布局
│   ├── main.tsx            # React 根挂载入口
│   └── index.css           # Tailwind v4 全局样式与自定义暗黑变量
├── public/                 # 静态资源目录
├── package.json            # 依赖配置与启动脚本
├── tsconfig.json           # TypeScript 编译配置
└── vite.config.ts          # Vite 打包配置
```
